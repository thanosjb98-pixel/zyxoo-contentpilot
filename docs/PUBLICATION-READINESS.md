# Public publication readiness checklist

This file tracks items that must be confirmed before a public directory submission. It is not a submission approval.

- [ ] Confirm verified individual/business publisher identity in the OpenAI submission portal.
- [ ] Confirm intended country availability (or explicitly choose all available countries).
- [ ] Confirm whether the plugin supports payments/purchases. Current package has no checkout or commerce integration; it creates content drafts only.
- [ ] Publish a privacy policy that accurately covers the actual plugin and platform data handling.
- [ ] Provide a working support contact/page.
- [ ] Confirm whether terms of service are required by the submission portal for this package.
- [ ] Review icon and listing copy.
- [ ] Upload the standalone plugin ZIP, inspect automated findings, and complete all required attestations.
- [ ] Test the final uploaded version and submit for review.
- [ ] Publish only after approval.

The current package is skills-only: it contains a skill and a bundled knowledge-base reference; no MCP server or connected app is included. According to current OpenAI submission guidance, skills-only plugins do not require MCP test cases or a demo recording, though all applicable listing, privacy, verification, and policy requirements still apply.
